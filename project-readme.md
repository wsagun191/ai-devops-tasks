# Simple Task API

REST API do efektywnego zarządzania zadaniami, zbudowane przy użyciu **Node.js**, **Express** oraz bazy danych **MongoDB**. Projekt oferuje pełne wsparcie dla operacji CRUD, zaawansowane filtrowanie oraz prosty system autoryzacji użytkowników.

---

## 📋 Opis
Simple Task API pozwala użytkownikom na bezpieczne rejestrowanie się, logowanie oraz zarządzanie własną listą zadań. Każde zadanie może posiadać status (np. *pending*, *completed*) oraz priorytet (np. *low*, *medium*, *high*), co ułatwia organizację pracy.

### Główne funkcje:
- **Pełne CRUD zadań:** Tworzenie, odczytywanie, aktualizowanie i usuwanie zadań.
- **Filtrowanie:** Wyszukiwanie zadań na podstawie statusu oraz priorytetów.
- **Autoryzacja:** Rejestracja i logowanie użytkowników oparte na tokenach (np. JWT).
